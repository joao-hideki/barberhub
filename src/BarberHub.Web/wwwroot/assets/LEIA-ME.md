# Kit visual da página inicial

Os arquivos desta pasta (CSS, JavaScript dos componentes, movimentos e layout) vêm do kit da skill
**taste-skill** (https://github.com/Leonxlnx/taste-skill, licença MIT), usada com o Claude Code para
redesenhar a página inicial. Eles são carregados só pela página inicial (`Pages/Index.cshtml`); as
demais telas usam `wwwroot/css/site.css`.
